# gobijan/homebrew-tap

Homebrew casks by [gobijan](https://github.com/gobijan).

## foot

[foot for macOS](https://github.com/gobijan/foot-macos), a native macOS
port of the fast, lightweight and minimalistic terminal emulator
[foot](https://codeberg.org/dnkl/foot):

```sh
brew install --cask gobijan/tap/foot
```

The cask is updated by foot's release script (`macos/publish.sh`).
